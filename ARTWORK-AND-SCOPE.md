# Artwork and implementation provenance

- `Game.java`: newly written simulation, generated road grid and fictional operating rules.
- `MainActivity.java`: newly written Android interface and vector drawing commands.
- Native edition: `CityMapView.java` draws the original offline schematic; `GamePanels.java` supplies Android controls. `WorldMapView.java` integrates MapLibre Native with OpenFreeMap/OpenStreetMap data and visible source attribution. There is no browser game runtime.
- `native-assets/history.json`: paraphrased historical records and selected numerical share-price observations with source URLs; see `HISTORICAL-NOTES.md`.
- `res/drawable/ic_launcher.xml`: newly drawn vector cab icon.
- Text: newly written game copy and paraphrased historical context; no extracted dialogue or campaign scripts.
- UI fonts: Android system fonts. Street-map styles/glyphs come from the map provider.
- Libraries: Android/Java APIs and the open-source MapLibre Native Android SDK; no commercial game-engine assets or proprietary map API keys.
- Fareforge identity: original code-drawn city illustration, navigation icons, and launcher monogram. The display name changes while the Android package/save identity remains compatible.
- Original PC archive: no files copied into this game or its source distribution.
- Product identity: provisional game and rival-company names; trademark clearance not performed.
